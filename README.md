# CtyunHelper

CtyunHelper 是一个面向 Windows 的天翼云电脑助手，用于自动保活、积分任务和积分商品兑换。

## 下载

从 [Releases](https://github.com/uvwt/CtyunHelper/releases) 下载程序后直接运行即可，无需额外安装运行环境。

## 主要功能

- 天翼账号登录与设备绑定
- 云电脑自动保活，断线后自动恢复
- 查看积分和积分任务状态
- 自动完成 AI 对话积分任务
- 查看“登录AI云电脑 / 使用1小时 / 与AI对话1次”任务状态
- 自动兑换积分商品
- Windows 登录后自动启动
- 系统托盘运行

## 首次使用

1. 启动 CtyunHelper。
2. 点击“账号登录”，输入天翼云电脑账号和密码。
3. 如遇验证码或设备绑定，按提示完成验证。
4. 登录成功后，程序会自动连接可用云电脑并开始保活。

关闭主窗口后程序仍会在系统托盘运行。如需完全停止，请从托盘菜单选择“退出”。

## 自动兑换

自动兑换默认关闭。点击“兑换设置”后，可以选择：

- 云电脑
- 兑换商品
- 单次最多兑换次数
- 每天、每隔若干天或每月指定日期执行

> **说明：** 兑换积分商品会导致绑定的云电脑重启。如果 CtyunHelper 安装并运行在该云电脑内，重启后可能无法自动保活。

如果上一笔兑换结果无法确认，程序会停止后续自动兑换，避免重复下单。

## 数据与日志

- 账号凭据保存在 Windows 系统凭据中。
- 日志中的敏感信息会自动脱敏。
- 退出账号会清除本地登录凭据和当前账号状态。
- 日志可直接从主窗口或托盘打开。

日志文件默认位于：

```text
%LOCALAPPDATA%\CtyunHelper\logs\CtyunHelper.log
```

## 更新

退出正在运行的 CtyunHelper，从 [Releases](https://github.com/uvwt/CtyunHelper/releases) 重新下载程序并运行即可。已有配置和登录信息不会因为替换程序文件而自动丢失。
