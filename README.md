# CtyunHelper

CtyunHelper 是一个面向 Windows 的天翼云电脑助手，提供自动保活、积分任务、AI 任务和积分商品自动兑换等功能。

程序为单文件 `CtyunHelper.exe`，下载后即可运行，不需要安装 Docker、Python、Chromium、.NET 或其他运行环境。

## 下载

前往 [Releases](https://github.com/uvwt/CtyunHelper/releases) 下载最新版本：

- Windows：`CtyunHelper.exe`

下载后双击运行即可。建议始终从本仓库 Release 页面获取程序。

## 主要功能

- 天翼账号登录与设备绑定
- 登录后自动连接云电脑并持续保活
- 保活断线自动恢复
- 查询当前积分和积分任务状态
- 自动完成 AI 对话积分任务
- 查看“登录AI云电脑 / 使用1小时 / 与AI对话1次”三个积分任务状态
- 自动兑换积分商品
- 可选择兑换云电脑、商品、最大次数和执行周期
- Windows 登录后自动启动
- 系统托盘运行
- 内置运行日志与敏感信息脱敏

## 首次使用

1. 启动 `CtyunHelper.exe`。
2. 点击“账号登录”，输入天翼云电脑账号和密码。
3. 如果天翼要求验证码或设备绑定，按窗口提示完成验证。
4. 登录和绑定成功后，程序会自动选择可用云电脑并开始保活。
5. 主窗口显示“保活状态 ● 在线”时，表示当前保活连接正常。

关闭主窗口只会隐藏到系统托盘，保活不会停止。要完全停止程序，请从托盘菜单选择“退出”。

## 首页状态

首页分为“核心状态”和“积分任务”两部分。

### 核心状态

- **保活状态**：当前云电脑保活是否在线、连接中或等待重连。
- **当前云电脑**：当前用于保活的云电脑。
- **当前积分**：当前通用积分余额。
- **积分同步**：最近一次积分和任务状态同步时间。
- **自动兑换**：当前自动兑换计划状态。
- **配置云电脑**：自动兑换绑定的云电脑。
- **兑换商品**：当前配置的兑换商品和所需积分。
- **最近异常**：最近一次运行异常；无异常时显示“无”。

### 积分任务

程序会直接读取天翼返回的三个积分任务状态：

- 登录AI云电脑
- 使用1小时
- 与AI对话1次

任务完成后会显示绿色 `● 已完成`。

## 自动保活

账号已经登录并完成设备绑定后，CtyunHelper 会自动启动保活，不需要手动点击。

程序会在连接中断后自动重新建立保活连接。最小化或隐藏到托盘不会影响保活；只有退出 `CtyunHelper.exe` 才会停止。

## AI 与积分任务

CtyunHelper 可以自动执行“与AI对话1次”积分任务，也可以通过主界面的“执行 AI 任务”手动触发。

“刷新积分”只会读取当前积分和任务状态，不会兑换商品。

为了避免异常情况下重复操作，程序对自动任务设置了运行次数、失败冷却和不重入保护。

## 自动兑换

自动兑换默认关闭。

点击主界面的“兑换设置”后，程序会自动刷新当前账号的云电脑和可兑换商品。选择目标后可以设置：

- 兑换云电脑
- 兑换商品
- 最大兑换次数
- 每天执行
- 每隔若干天执行
- 每月指定日期执行

保存后无需重启即可生效。

自动兑换执行前会重新检查当前积分、商品状态和云电脑，避免使用过期配置。如果程序在下单过程中异常退出，导致结果无法确认，后续自动兑换会停止并要求人工确认，不会直接重复下单。

## 设置

“设置”页面目前提供：

- 启用 / 停用 AI 和兑换自动任务
- Windows 登录后自动启动 CtyunHelper

开机自启动使用当前 Windows 用户配置，不需要管理员权限。

## 托盘

关闭主窗口后程序会继续在系统托盘运行。托盘菜单可以快速执行：

- 打开主界面
- 执行 AI 任务
- 刷新积分
- 检查 / 执行兑换
- 打开兑换设置
- 打开设置和日志
- 查看关于信息
- 退出账号
- 退出程序

## 数据与安全

- 账号密码保存到 Windows Credential Manager。
- 登录 Profile 等敏感缓存使用 Windows DPAPI 保护。
- 日志写入前会对密码、Token、Ticket、DeviceCode 等敏感信息进行脱敏。
- 退出账号会清除本地登录凭据和当前账号状态。
- 自动兑换默认关闭，只有用户明确配置并启用后才会执行。

## 日志

可以直接从主窗口或托盘打开“日志”页面查看运行记录。

日志文件通常位于：

```text
%LOCALAPPDATA%\CtyunHelper\logs\CtyunHelper.log
```

日志会自动滚动并限制历史文件数量，不会无限增长。

如果遇到登录、保活、积分、AI 或兑换异常，建议先查看日志中的最近错误。

## 更新

下载新版 `CtyunHelper.exe` 后退出旧版本，再用新版文件替换即可。用户配置、登录凭据和运行状态保存在 Windows 用户目录中，不会因为替换 EXE 自动丢失。
